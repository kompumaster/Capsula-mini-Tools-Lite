# micro_server: веб-портал настроек колонки

Пакет для MicroPython на VK Капсуле Мини. Поднимает локальный
HTTP-сервер, через который браузер или телефон в той же сети смотрит
состояние колонки. Управление настройками — в следующих версиях.

Статус: каркас, страница состояния, статические страницы, настройки
и `/api/status` готовы; управление настройками — впереди.

## Что умеет сейчас

- страница состояния: хост, платформа, ядро, uptime, время, память;
- сеть только для чтения: текущая Wi-Fi, состояние, IP, сохранённые;
- громкость и версии пакетов;
- динамическое обновление страницы без перезагрузки (раз в 15 с);
- HTML, CSS и JS — отдельными файлами, отдаются из памяти;
- тестовая страница и JSON `/api/status`;
- настройки в JSON с атомарной записью.

## В планах

- управление громкостью и часовым поясом;
- Wi-Fi настройки — только по отдельному решению (сейчас это
  единственная связь с колонкой);
- режимы AP/STA и запуск сервера.

## Что нужно на колонке

- MicroPython;
- `micro_hal` для Wi-Fi, громкости и времени;
- `MICROPYPATH` с `/home/microp` и `.frozen`:

  ```sh
  MICROPYPATH=/home/microp:/usr/lib/micropython:.frozen
  ```

## Куда ставится

```text
/home/microp/micro_server/              пакет
/home/microp/micro_server/settings.json настройки
/home/microp/micro_hal/                 оборудование
```

## Страницы

- `/` — общая информация о колонке: система, сеть (только чтение),
  звук, версии, память; обновляется сама раз в 15 секунд;
- `/test` — тестовая страница с кнопкой проверки API;
- `/api/status` — те же данные в JSON.

## Как открыть

Сейчас — в домашней сети: `http://<адрес колонки>:8080/`.
Режим точки доступа (`10.0.0.1`) — в планах.

## Настройки

Файл `/home/microp/micro_server/settings.json` — порт, часовой пояс.
Пишется атомарно (временный файл + `rename`); при повреждении берутся
значения по умолчанию. Пароли Wi-Fi здесь не хранятся. Текущие
настройки отдаёт `GET /api/status`.

## Встраивание в оркестратор

```python
from micro_server import MicroServer
from micro_server.pages import register

server = MicroServer(port=8080)
register(server)
server.start()

while running:
    server.poll(0)      # 0 — не ждать, 0.1 — ждать до 0.1 с
    # ... остальная работа оркестратора

server.stop()
```

`serve_forever()` остаётся для запуска отдельным процессом.

## Ограничения первой версии

- только локальная сеть, без TLS;
- Wi-Fi, громкость и время — только чтение, без управления;
- режим точки доступа не встроен;
- нет OTA-обновлений и файлового менеджера;
- один запрос за раз;
- пароли Wi-Fi хранит система, а не портал.

## Состав пакета

```text
micro_server/
  __init__.py   публичные имена и версия
  server.py     сервер и цикл
  utils.py      разбор запроса и ответы
  info.py       снимок состояния колонки
  pages/        static.py: отдача web/ из памяти
  web/          HTML, css/style.css, js/app.js, js/test.js
  api/          JSON: status, ping
  store.py      настройки в JSON
  config.py     порт, лимиты, пути
  errors.py     ServerError
  examples/     примеры запуска
```
