# Сторонние компоненты

## micropyserver

- источник: https://github.com/troublegum/micropyserver
- лицензия: MIT, Copyright (c) 2019 troublegum

`server.py` и `utils.py` проекта `micro_server` созданы на основе
MicroPyServer: сокет-цикл, таблица маршрутов, разбор запроса и
помощники ответа. Код адаптирован под пакет, но структура и идеи
взяты из оригинала.
