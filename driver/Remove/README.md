# Удаление драйвера Капсулы Мини

Утилита — **DriverStore Explorer** (Rapr), официальные релизы:

```
https://github.com/lostindark/DriverStoreExplorer/releases/
```

## Как удалить

1. Запустите `Rapr.exe` и подтвердите запрос администратора (UAC).
2. В строке поиска введите `Капсула`.
3. В списке снизу отметьте галочкой найденный драйвер.
4. Нажмите кнопку `Delete Driver` (удалить драйвер) и подтвердите.
