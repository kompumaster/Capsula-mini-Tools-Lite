# Zadig 2.9 для Капсулы Мини

Ручной вариант установки WinUSB для USB-загрузчика.

## Состав

| Файл | Назначение |
|---|---|
| `zadig-2.9.exe` | официальный релиз Zadig 2.9 (libwdi 1.5.1) |
| `zadig.ini` | настройки: WinUSB, список всех устройств, выход после успеха |
| `capsula_mini.cfg` | preset с VID/PID и именем устройства |

## Как установить

1. Запустите `zadig-2.9.exe` и подтвердите UAC.
2. В Zadig выберите `Device -> Load Preset Device`.
3. Укажите файл `capsula_mini.cfg`.
4. Проверьте, что в поле драйвера выбран `WinUSB`.
5. Нажмите `Install Driver`.
6. Дождитесь сообщения об успехе.
   Zadig закроется сам.
7. Подайте питание на плату. Windows подхватит драйвер при появлении
   устройства.
